# Пояснения к заданиям (для себя, учителю не сдавать)

Все проекты: .NET Framework 4.7.2, Windows Forms. Открывать файлом `.slnx` в Visual Studio.
Учителю сдаётся архив папки проекта без `bin`, `obj`, `.vs` (готовые архивы лежат в папке `архивы`).

Общее для всех: в `Form1()` только `InitializeComponent()`, всё, что происходит при запуске, в `Form1_Load`.
Свойства элементов, пункты списков и привязка событий заданы в конструкторе форм (окно «Свойства»).

## Задание 2: радиокнопки, калькулятор и картинки
- `ReadNumber(TextBox)` берёт число с умолчанием: если не парсится, будет 0.
- Каждое поле отвечает только за свой операнд (`textBox1_TextChanged` → `a`, `textBox2_TextChanged` → `b`), после любого изменения вызывается `Calculate()`.
- Один обработчик на 4 радиокнопки операций: `RadioButton rb = (RadioButton)sender; if (rb.Checked == true) ...`, операция берётся из `rb.Text`.
- Деление на 0 исключено: вместо результата пишется «на 0 делить нельзя».
- При запуске уже выбраны «+» и «Кот», в полях 0.
- Картинки: один обработчик, номер картинки лежит в свойстве `Tag` радиокнопки.
- **Почему искажаются изображения:** у `imageList` по умолчанию `ImageSize = 16x16` и цвет 8 бит, поэтому картинки сжимаются до 16x16, а потом растягиваются в pictureBox. Здесь поставлено `ImageSize = 128x128`, `ColorDepth = Depth32Bit`, все картинки 128x128, у pictureBox `SizeMode = Zoom`.

## Задание 3: класс «Ланч», вариант 22
- Класс `Lunch`: 3 названия и 3 цены, конструктор по умолчанию и с параметрами, `ToString()`, `TotalCost()` — общая стоимость, `CostWithDiscount()` — со скидкой 5%. Аксессоры `Dish1..Dish3` — это названия блюд.
- Объект создаётся один раз полем формы, дальше меняются только его свойства.
- Каждое поле ввода меняет только своё поле объекта, справа сразу видно текущее состояние.
- Кнопки вызывают методы объекта.

## Задание 4: объект Pic, меню, панель, контекстное меню
- В `Pic.cs` исправлено: в исходном файле преподавателя свойства `Dir` и `Size` были перепутаны.
- Контроль выхода за границу сделан внутри `Left/Right/Up/Down`. Ширина и высота клиентской области берутся только в `Right` и `Down` (`Pb.Parent.ClientSize`) с учётом размера картинки `size`.
- Таймер включён сразу (`Enabled = true`).
- Меню: Направление (Ctrl+стрелки), Вид (Ctrl+1/2/3), Размер (F2/F3), Скорость (F5/F6), Выход. У пунктов есть картинки.
- Контекстное меню картинки (правая кнопка) повторяет пункты «Вид» и вызывает их обработчики.
- Панель: один обработчик `toolStrip1_ItemClicked` вызывает пункты меню. Выпадающий список скорости тоже вызывает пункты меню.

## Задание 5: текстовый редактор, меню «Файл»
- Создать / Открыть / Сохранить / Сохранить как / Выход, кнопки на панели через один обработчик.
- Если текст менялся (`richTextBox1.Modified`), появляется вопрос «Сохранить?» с кнопками Да/Нет.
- Тестовые тексты лежат в папке проекта `Тексты`, диалог открытия сразу открывается в ней.
- Редактирования (копировать/вставить) здесь нет — его нет в задании.

## Задание 6: «Правка», «Сервис», строка состояния
- Вырезать/Копировать/Вставить через `Clipboard` в формате Rtf (как в методичке), Выделить всё.
- Контекстное меню текста вызывает пункты главного меню.
- Сервис → Настройки → Цвет текста / Цвет фона / Шрифт (ColorDialog и FontDialog добавлены на форму как элементы).
- Строка состояния: имя файла, дата, строка и символ под курсором.
- Тест: открыть `Тексты/форматирование.rtf`.

## Задание 7: диалоги, поиск, вариант 4
- Диалоги → Диалог_текст (Ctrl+T): выделить слово, вызвать диалог, ввести новое, ОК — слово заменится.
- Диалоги → Диалог_дата (Ctrl+D): поставить курсор после «Собрание по практике состоится» (`Тексты/собрание.rtf`), выбрать дату, ОК — дата вставится.
- В диалогах кнопки ОК/Отмена присваивают `DialogResult`.
- Поиск: ввести текст в поле на панели, «Найти» (или Правка → Найти, Ctrl+F) — все вхождения подсветятся.
- **Вариант 4** (у тебя 22, вариантов 18, поэтому 22 − 18 = 4): Сервис → «Подсчет знаков . ? !» (F9). Функция `CountMarks(String s, String marks)` считает, сколько символов строки входят в набор. Считается по выделенному фрагменту или по всему тексту. Текст не меняется, поэтому форматирование не теряется. Используется String, а не StringBuilder.
- Тест: `Тексты/знаки.rtf` (в нём 6 точек, 3 вопросительных знака и 2 восклицательных).

## Задание 9: таблица сотрудников (оцениваются пункты 1–3)
- Класс `Record`: Name, Birthday, Profession, Department, Money, конструкторы, `ToString()`.
- Заголовки столбцов взяты из атрибута `[DisplayName("...")]` у свойств, поэтому в коде не нужны строки вроде `Columns[0].HeaderText = ...`.
- `List<Record> Table` — источник данных для `dataGridView1`. `Redraw()` снимает `DataSource` и назначает его заново.
- Щелчок по строке выводит запись в поле внизу.
- Правка → Добавить (Ctrl+N) / Изменить (Ctrl+E) / Удалить (Delete). Добавление и изменение идут через отдельные диалоги `DialogAdd` и `DialogEdit`, запись передаётся через `static public Record Rec`. Удаление спрашивает подтверждение.
- Операции_с_данными: сортировка по имени и по окладу (`List.Sort`).
