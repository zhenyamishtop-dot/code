# Gogi Trade

Telegram-бот и мини-приложение для трейдинга NFT-подарками. Бот следит за новыми лотами на **Portals, MRKT, Tonnel и Getgems** через API [Gift Satellite](https://t.me/gift_satellite_app) и сразу присылает уведомление:

- подарок, маркет и цена, модель / фон / узор с редкостью;
- флор коллекции на маркете лота и флор модели на всех четырёх маркетах, с разницей в процентах;
- последние 5 продаж этой модели на всех маркетах: цена, когда продан, ссылка на сам подарок;
- кнопки «Купить на <маркет>» (открывает лот в маркете) и «Подарок» (карточка в Telegram).

Фильтры настраиваются в мини-приложении: любые из коллекций, а внутри — конкретные модели, фоны, узоры, потолок цены и отклонение от флора модели.

## Как это работает

- Источник данных — официальный «Доступ к API» Gift Satellite (ключ в профиле). Лимит API — **1 запрос поиска в секунду на маркет на каждый ключ**. Можно указать несколько ключей (`SATELLITE_TOKENS=k1,k2,…`): коллекции делятся между ключами поровну, круг опроса ≈ коллекций ÷ ключей секунд. Ключ, который API отклонил (401), автоматически выключается, его коллекции забирают остальные.
- Поиск отдаёт 50 самых дешёвых лотов под фильтр. Если в фильтре выбраны модели/фоны/узоры, они уходят прямо в запрос, и бот видит 50 самых дешёвых лотов именно по ним.
- Лот считается новым, если бот его ещё не видел и он создан не раньше `FRESH_WINDOW_SEC` секунд назад (иначе это старый лот, который просто поднялся в топ-50 после продаж).
- «Снижение цены» — отдельный тип уведомления: уже выставленный лот подешевел минимум на заданный процент.

## Запуск

Нужен Node.js 20+ (зависимостей нет).

```bash
cp .env.example .env   # заполните BOT_TOKEN и SATELLITE_TOKENS
npm start
```

Без `WEBAPP_URL` бот работает полностью, но без кнопки мини-приложения; фильтры задаются командами `/add Lol Pop`, `/remove Lol Pop`, `/list`.

Команды бота: `/start`, `/status`, `/list`, `/add`, `/remove`, `/pause`, `/resume`, `/test`.

## Развёртывание на сервере (24/7 + мини-приложение)

Мини-приложению нужен публичный HTTPS-адрес. Самый простой путь — любой VPS с Docker (хватит 1 vCPU / 512 МБ):

1. Установите Docker: `curl -fsSL https://get.docker.com | sh`
2. Скопируйте папку `gogi-trade` на сервер, создайте `.env`:
   ```
   BOT_TOKEN=...
   SATELLITE_TOKENS=ключ1,ключ2
   OWNER_ID=<ваш Telegram ID>
   DOMAIN=203-0-113-10.sslip.io        # IP сервера через дефисы, или свой домен
   WEBAPP_URL=https://203-0-113-10.sslip.io
   ```
3. Откройте порты 80 и 443 и запустите: `docker compose up -d --build`

Caddy сам получит сертификат. После старта бот поставит кнопку меню «Gogi Trade», открывающую мини-приложение.

## Безопасность

- Ключи `SATELLITE_TOKENS` дают доступ к аккаунтам и балансам их владельцев в Gift Satellite; `BOT_TOKEN` — к боту. Храните их только в `.env` (он в `.gitignore`). Ключ перевыпускается в профиле Gift Satellite его владельцем, токен — командой `/revoke` в @BotFather.
- Бот приватный: владелец — `OWNER_ID` (если не задан — первый, кто нажал `/start`). Когда боту пишет кто-то ещё, владельцу приходит запрос с кнопками «Разрешить / Отклонить». Список друзей — `/users`, закрыть доступ — `/deny ID`. У каждого свои фильтры; лимит API общий, поэтому коллекции всех пользователей складываются в один круг опроса.
- API мини-приложения принимает только запросы с подписью Telegram (`initData`), проверяемой токеном бота.

## Разработка

```bash
npm test                                   # модульные тесты
node tools/ui-preview.mjs <telegramId>     # прогон мини-приложения в headless-браузере (нужен Playwright)
```

Структура: `src/poller.js` — опрос и поиск новых лотов, `src/notifier.js` — текст уведомления, `src/floors.js` — кэш флоров, `src/filters.js` — фильтры, `src/bot.js` — команды, `src/server.js` — API мини-приложения, `web/` — мини-приложение.

## Запуск на своём компьютере (Windows, бесплатно)

В PowerShell:

```powershell
irm https://raw.githubusercontent.com/zhenyamishtop-dot/code/claude/casemint-model-gifts/gogi-trade/windows/install.ps1 | iex
```

Установщик ставит Node.js (если его нет), скачивает Gogi Trade в `%USERPROFILE%\GogiTrade`, спрашивает токен бота и ключ Gift Satellite и создаёт ярлык «Gogi Trade» на рабочем столе. Ярлык поднимает бесплатный туннель Cloudflare (публичный HTTPS-адрес для мини-приложения, меняется при каждом запуске) и запускает бота. Бот работает, пока открыто его окно и компьютер не спит.
