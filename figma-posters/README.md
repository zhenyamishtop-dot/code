# Практическое занятие 2 — плакаты «Путешествия»

Два рекламных плаката на одну тему («Туризм»), в одном стиле. Они собраны из одних и тех же
композиционных элементов: палитра бирюзовый / оранжевый / тёмно-синий, шрифт Inter,
общие заголовок и текст, скруглённые линии, сетки точек, фото в геометрической рамке.
Отличается только композиционный принцип.

| Файл | Принцип | Как построен |
|---|---|---|
| `poster-1-static.svg` | **Статика** | Центральная ось и симметрия, фото в круге по центру, горизонтальные линии, текст по центру, три одинаковых блока снизу, одинаковые сетки точек слева и справа |
| `poster-2-dynamic.svg` | **Динамика** | Диагонали под 45°, три фото в повёрнутых квадратах-ромбах разного размера, наклонные линии, асимметрия, текст выровнен вправо, элементы срезаны краем листа |

Размер 840×1188 (пропорции A4). PNG — превью. Исходные фото лежат в `photos/`.

## Как открыть в Figma / Pixso

1. Перетащите `.svg` на холст (или **File → Import**).
2. Получится фрейм с именованными группами: «Фото круг», «Заголовок», «Акция», «Подвал» и т. д.
3. Тексты остаются редактируемыми (шрифт Inter). Фото вставлены как заливки и обрезаны масками
   по кругу или ромбу.

Перегенерировать: `python3 generate.py` (нужен Pillow).
