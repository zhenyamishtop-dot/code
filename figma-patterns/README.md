# Геометрические паттерны для Figma

Два простых паттерна по мотивам референсов: сетка 4×4 из квадратных плиток,
в каждой плитке — одна-две базовые фигуры (круг, полукруг, четверть круга,
треугольник, ромб, квадрат, полосы), палитра из 4 цветов.

| Файл | Паттерн | Палитра |
|---|---|---|
| `pattern-1-warm.svg` | «Тёплый» | `#FF6B57` `#FFC94A` `#0E9384` `#FFF4DC` |
| `pattern-2-night.svg` | «Ночной» | `#241A4A` `#F48FB1` `#6FD6C0` `#FFF3E3` |

PNG рядом с каждым SVG — превью.

## Как открыть в Figma

1. Перетащите `.svg` на холст Figma (или **File → Import…**).
2. Получится фрейм 1200×1200 с 16 группами `01 Полукруг`, `02 Четверть круга`… —
   каждая плитка 300×300 обрезана маской по своему квадрату.
3. Все фигуры — обычные векторы, их можно двигать и перекрашивать.
   Палитру целиком удобно менять через **Selection colors**.

Перегенерировать (например, после смены цветов в константах): `python3 generate.py`.
