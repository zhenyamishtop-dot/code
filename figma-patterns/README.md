# Геометрические паттерны для Figma

Два паттерна в стиле присланных референсов: сетка 4×4 из квадратных плиток,
плоские геометрические фигуры, ограниченная палитра.

| Файл | Тема | Палитра |
|---|---|---|
| `pattern-1-sea.svg` | «Морской закат»: закат, радуга, рыба, чешуя, парусник, ракушка, морская звезда, чайки, цветок… | `#FF6B57` `#FFC94A` `#0E9384` `#12355B` `#FFF4DC` `#8FD3E8` |
| `pattern-2-space.svg` | «Космос»: луна, планета, созвездие, ракета, комета, портал, НЛО, орбиты, звезда… | `#241A4A` `#5B3E96` `#F48FB1` `#FFB37A` `#C9B6F2` `#FFF3E3` `#6FD6C0` |

PNG рядом с каждым SVG — превью.

## Как открыть в Figma

1. Перетащите `.svg` на холст Figma (или **File → Import…**).
2. Получится фрейм 1200×1200 с 16 группами `01 Закат`, `02 Радуга`… — каждая плитка 300×300
   и обрезана маской по своему квадрату.
3. Все фигуры — обычные векторы (круги, многоугольники, контуры): цвета и форму можно
   менять. Удобно сразу вынести цвета в стили: выделите фрейм → панель **Selection colors**.

Если нужно перегенерировать (например, сменить палитру — константы в начале
каждого блока): `python3 generate.py`.
