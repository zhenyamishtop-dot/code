# Практическое занятие 3 — абстрактная композиция «Мода»

Два плаката 1080×1350 на тему «Мода». В каждом простые геометрические фигуры
(органичная клякса, круги, круг в полоску, полупрозрачные прямоугольники) сочетаются
с вырезанным из фона фото. Человек «выходит» из фигуры: тело внутри цветной кляксы,
а голова (и поднятая рука на втором плакате) выходят за её край. Цвета фото изменены:
на первом плакате оно чёрно-белое, на втором — в фиолетовом дуотоне.

| Файл | Палитра | Заголовок |
|---|---|---|
| `poster-1-fashion.svg` | коралловый + голубой, фото Ч/Б | ЭЛЕГАНТНОСТЬ · 01 |
| `poster-2-fashion.svg` | фиолетовый + персиковый, фото в фиолетовом дуотоне | ВЕЧЕРНИЙ ОБРАЗ · 02 |

PNG рядом с каждым SVG — превью. В `photos/` лежат исходники (`photo-*.webp`) и
вырезанные фото без фона (`cutout-*.png`).

## Открыть готовый плакат

Перетащите `.svg` в Figma или Pixso. Тексты (шрифт Inter), фигуры и маски остаются редактируемыми.

## Как повторить вручную в Figma

1. **Вырезать фото.** Перетащите `photo-1.webp` в Figma → плагин *Remove BG*
   (или готовый `cutout-1.png`).
2. **Поменять цвет.** Выделите фото → *Fill* → *Image* → *Saturation* −100 (Ч/Б).
   Для дуотона сверху положите прямоугольник фиолетового цвета в режиме *Color*
   и сделайте его маской по фото.
3. **Фигура.** Пером (P) нарисуйте кляксу и залейте её цветом палитры.
4. **«Выход» из фигуры.** Скопируйте кляксу, добавьте к ней прямоугольник над линией
   плеч → *Union*. Положите получившуюся фигуру под фото, выделите обе → *Use as mask*
   (Ctrl+Alt+M). Тело останется внутри кляксы, голова выйдет за её край.
5. **Геометрия вокруг.** Круги (O), круг в полоску (линии + маска по кругу),
   полупрозрачный прямоугольник (*Opacity* 55%).
6. **Текст.** Углы: «НЕДЕЛЯ МОДЫ», «МОДА / СТИЛЬ», заголовок, номер. Боковые надписи
   повёрнуты на 90°.

Перегенерировать SVG: `python3 generate.py` (нужен Pillow).
